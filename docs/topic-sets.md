* **このファイルと`Assets/Resources/dialogue/S1`・`S2`のCSV、`Assets/Resources/PromptData/S1`・`S2`のプロンプトは同じ内容にする**。セリフやプロンプトを変えるときは、ここを直してからデータを作り直す（CSVはこの表と5.3の型から機械的に作れる）

## 3. 2つのセットの対応

| | セット1 | セット2 |
|---|---|---|
| 人数・位置 | 6人（NPC001〜006の位置） | 同じ |
| 衣装 | 商人・平民・薬師・貴族・鍛冶屋・料理人 | 同じ6種類を、どの位置でもセット1と違うように入れ替える |
| 話題 | 1人2つ（仕事のこと・村の人のこと）、各2ノード | 同じ |
| 話題2のつながり | 6人で1つの輪（全員が1回ずつ紹介される） | 同じ |
| 話題の調子 | 村の暮らしの軽い話（事件や謎はない） | 同じ |
| 自由入力（条件B） | 6人とも、あいさつのあとは自由入力だけ（README 1.8） | 同じ |

* 話題2では、紹介する人の**居場所**（「東の桟橋の手前」など）を必ず言う。ミニマップと合わせて、次に話す人を探せる
* プロンプトの【知っている情報】には、セリフの内容に加えて、**自分を紹介している人とのつながり**も書いた（例：ヤニスは、ティムが道具を直してもらったと話す相手なので、「ティムの道具を直した」ことを知っている）。自由入力で「〇〇さんがあなたのことを話していたよ」と聞かれても話が食い違わないようにするため。セリフ（選択肢で聞ける内容）には出てこない情報だが、相手のセリフで既に話されている事実の裏返しなので、新しい話題にはならない
* セット1はクエスト版（docs/history.md）と名前・性格は同じだが、会話もプロンプトも新しく書いたもの。クエスト版の手がかり（薬草・灯篭）は出てこない（ニコラの収穫祭の灯篭は飾る話だけで、なくなってはいない）

## 4. チュートリアル

案内役の2人（README 2.4）。話題セットとは別で、両セット・両条件で同じ。村・村の人たちには触れない。

### 会話（`Resources/dialogue/Tutorial/`）

選択肢・遷移はどちらも同じ：`0` 話を聞く → `10` ／ なんでもない → `90`、`10` 2つの選択肢 → `20`・`30`、`20`・`30` → `99`、`90`・`99` で終わり。`action`・`allowInput`はなし。

**TUT001 案内人ケビン**

| id | 発言 | 選択肢 |
|---|---|---|
| 0 | やあ、ぼくはケビン。ここで少し練習していこう。 | 話を聞く／なんでもない |
| 10 | 何の話をしようか。 | 天気のこと／この広場のこと |
| 20 | 今日はよく晴れているね。こういう日は歩くだけで気持ちがいいよ。 | |
| 30 | ここは練習用の広場なんだ。好きなように歩き回っていいよ。 | |
| 90 | そうかい。またいつでもどうぞ。 | |
| 99 | 話せてよかった。向こうにいるクリスにも話しかけてみて。 | |

**TUT002 旅人クリス**

| id | 発言 | 選択肢 |
|---|---|---|
| 0 | こんにちは。ぼくはクリス、旅の途中なんだ。 | 話を聞く／なんでもない |
| 10 | 旅の話でもしようか。 | 旅のこと／好きなもの |
| 20 | 山を三つ越えて、ここまで歩いてきたんだ。足はもうくたくただよ。 | |
| 30 | 旅先で見る朝焼けが好きなんだ。どこで見ても少しずつ色がちがうからね。 | |
| 90 | そっか。また会おう。 | |
| 99 | じゃあね。よい一日を。 | |

### プロンプト（`Resources/PromptData/Tutorial/`）

【村の人たち】は書かない。【知らない情報】に「村や村の人たちのことは知らない。聞かれたら『分からない』と答える」を1行足し、それ以外の【知らない情報】【会話のルール】はREADME 4.5のテンプレートどおり。

**TUT001 案内人ケビン**

```text
あなたは練習用の広場にいる案内人のケビンです。
【性格】明るく親切。
【背景】広場で、はじめて来た人の話し相手をしている。
【知っている情報】
- 今日はよく晴れていて、歩くだけで気持ちがいい
- ここは練習用の広場で、好きなように歩き回ってよい
- 広場の向こうに、旅人のクリスがいる
```

**TUT002 旅人クリス**

```text
あなたは練習用の広場で休んでいる旅人のクリスです。
【性格】のんびりしていて人なつっこい。
【背景】旅の途中で、広場でひと休みしている。
【知っている情報】
- 山を三つ越えて、ここまで歩いてきた。足はもうくたくた
- 旅先で見る朝焼けが好き。どこで見ても少しずつ色がちがう
- 広場には案内人のケビンがいる
```
